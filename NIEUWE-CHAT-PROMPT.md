# Prompt om een nieuwe chat te starten

Plak dit als eerste bericht in een nieuwe chat — bij voorkeur **Claude Code lokaal op de PC** in de
repo-map (desktop-app of `claude` in een terminal in de Vortex-map), anders Claude Code op het web met
repo `syneyexx/Vortex`.

---

We gaan verder met mijn project **Vortex** (repo `syneyexx/Vortex`). Antwoord in het Nederlands.

1. Lees `CLAUDE.md` en volg die. Begin met `VAULT/OVERDRACHT.md` (stand van zaken, architectuur,
   opdracht), daarna `VAULT/00-START.md`, `VAULT/01-REGELS.md`, `VAULT/12-NAVIGATIE.md` en onderaan
   `VAULT/LOG.md`. Lees **niet** het hele project; code alleen via `VAULT/20-CODEMAP.md` → `CARD.md`
   → `python tools/vault/vault.py find <ID>`. Endpoints/CLI/config staan in `VAULT/30-API-EN-CONFIG.md`.
2. Je opdracht staat in `VAULT/OVERDRACHT.md` §4: de installatie op mijn Windows-PC afmaken
   (`install.bat` → bekijk `install.log`, eerst de pnpm-fout), modellen klaarzetten, Vortex starten met
   `start_vortex.bat`, en daarna stap voor stap `VAULT/PC-VERIFICATIE.md` doorlopen.
3. Werk de VAULT bij na elk stuk werk en draai `python tools/vault/vault.py check`.
   Grote tests alleen als ik "GROTE TESTEN NU" zeg; W19/W20 alleen op het exacte commando.
